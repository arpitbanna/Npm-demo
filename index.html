Quick Start & Documentation

        
Integrates effortlessly into any JavaScript or React project in seconds.

      


      

        
        

          
📦 Installation

          

            
            
            
            
          

          
npm install magicui-effects


          
Vanilla JavaScript

          
import { confetti, snow } from 'magicui-effects';

// Fullscreen effect
const snowEffect = snow({ count: 120, speed: 2 });

// Container specific
const confettiEffect = confetti({
  target: '#celebration-box',
  continuous: false
});

// Trigger a burst later
confettiEffect.burst({ count: 80 });

        


        
        

          
⚛️ React Integration

          

            Use inside useEffect with clean unmounting to guarantee zero memory leaks:
          

          
import React, { useEffect, useRef } from 'react';
import { stars } from 'magicui-effects';

export function StarryHero() {
  const containerRef = useRef(null);

  useEffect(() => {
    const effect = stars({
      target: containerRef.current,
      count: 150,
      shootingStars: true
    });

    return () => {
      // Clean up canvas and event listeners on unmount
      effect.destroy();
    };
  }, []);

  return (
    <div ref={containerRef} style={{ width: '100%', height: 400 }}>
      <h1>Welcome to the Cosmos</h1>
    </div>
  );
}

        

      


      
      

        
📖 Effect Instance API

        

          Every effect returns an EffectInstance object with complete lifecycle control:
        


        

          

            
              

                Method
                Description
                Returns
              

            
            
              

                start()
                Resumes animation if paused.
                this
              

              

                stop()
                Pauses animation without removing canvas from DOM.
                this
              

              

                toggle()
                Toggles between playing and paused states.
                boolean
              

              

                update(options)
                Dynamically updates speed, particle count, colors, etc. at runtime without stutter.
                this
              

              

                clear()
                Clears current canvas pixels.
                this
              

              

                destroy()
                Cancels animation loop, removes event listeners, and unmounts canvas from DOM.
                void
              

              

                getCanvas()
                Returns the underlying HTMLCanvasElement.
                HTMLCanvasElement | null
              

              

                isActive()
                Returns whether animation is currently active.
                boolean
              

              

                getState()
                Returns current state object { active, destroyed, options }.
                Object
